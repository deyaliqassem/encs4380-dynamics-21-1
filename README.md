# Dynamic Characteristics Interactive Toolkit

**Course:** ENCS4380 – Interfacing Techniques  
**University:** Birzeit University  
**Instructor:** Dr. Wasel Ghanem

## Project Overview

This project is an interactive web-based toolkit designed to demonstrate the dynamic characteristics of measurement systems. It allows users to explore sensor behavior through interactive controls, mathematical models, and graphical visualizations.

## Checkpoint 1 – Module 1: First-Order Time Response

**Status:** Implemented

The first module demonstrates the time response of a first-order system using step and ramp inputs.

### Features

- Interactive sliders to adjust the gain (K) and time constant (τ).
- Step and ramp input selection.
- Real-time visualization of the input and sensor output.
- Response markers at 63.2% (τ) and 95% (3τ).
- Ramp lag and steady-state error calculations.
- Error-fraction plot using a logarithmic scale.
- Interactive "Predict, then Check" activity.
- Validation checks for the mathematical results.
