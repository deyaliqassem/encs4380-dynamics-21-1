Mathematical model
Differential equation:   τ dy/dt + y = Kx
Transfer function:   G(s) = K / (τs + 1)
Step response:   y(t) = KA(1 − e−t/τ)

K is the sensor gain, τ is the time constant, x(t) is the input, and y(t) is the sensor output.

For a step input, the normalized error fraction is:

e(t) / (KA) = e−t/τ   ⇒   ln(e/KA) = −t/τ

On a logarithmic y-axis, the exponential error fraction appears as a straight line. Its slope on a natural-log scale is −1/τ.

Mathematical model
Sine input:   x(t) = A sin ωt
Amplitude ratio:   M = 1 / √(1 + (ωτ)²)
Phase:   φ = −tan−1(ωτ)
Cutoff:   ωc = 1/τ   (M = 0.707, −3 dB, φ = −45°)
Dynamic error:   δ = M − 1

The time plot starts the sensor at rest, so you see the start-up transient fade into the steady-state sine: y(t) = A/(1+ω²τ²) · [ωτ e−t/τ + sin ωt − ωτ cos ωt].

Mathematical model
Transfer function:   G(s) = Kωn² / (s² + 2ζωns + ωn²)
Mass-spring-damper:   m ẍ + b ẋ + k x = F(t)   ⇒   ωn = √(k/m),   ζ = b / (2√(km))
Poles:   s = −ζωn ± ωn√(ζ² − 1)
Overshoot:   Mp = 100·e−πζ/√(1−ζ²) %,   peak time tp = π / (ωn√(1−ζ²))

Plots show the normalised step response (K = 1, final value 1). Move ζ and ωn, or m, b and k: the five sliders stay in sync.

Mathematical model & estimation guide
First-order step: y(t) = K(1 − e−t/τ)
First-order sine: G(s) = K/(τs + 1),   |G(jω)| = K/√(1 + (ωτ)²)
Second-order: G(s) = ωn²/(s² + 2ζωns + ωn²)

First-order step: estimate K from the final output and τ at 63.2%. For sine, use amplitude and phase lag. For underdamped second-order steps, use overshoot and peak time.

How to estimate the hidden parameters
First-order step: K ≈ final height; τ ≈ time at 63.2% of final height.
Log method: ln(error fraction) = −t/τ.
First-order sine: phase lag φ = −atan(ωτ); output amplitude = K/√(1+(ωτ)²).
Second-order underdamped: Mp = exp(−πζ/√(1−ζ²)); tp = π/(ωn√(1−ζ²)).

The second-order peak formulas apply to underdamped step responses. The stated sine frequency is in rad/s.
